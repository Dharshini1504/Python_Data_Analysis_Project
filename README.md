# Customer Dataset Cleaning

## Overview

This project focuses on cleaning and analyzing a customer sales dataset using Python and Pandas.

## Objectives

* Handle missing values
* Remove duplicate records
* Clean and standardize data
* Convert columns to appropriate data types
* Create a Total Sales column
* Perform basic sales analysis

## Technologies Used

* Python
* Pandas
* Jupyter Notebook

## Analysis Performed

* Product-wise sales analysis
* Category-wise sales analysis
* City-wise sales analysis
* Payment mode analysis
* Customer rating analysis

## Files

* `Customer_Dataset_Cleaning.ipynb` – Data cleaning and analysis
* `customer_sales_messy.csv` – Original dataset
* `Customer_Dataset_Cleaning.csv` – Cleaned dataset
